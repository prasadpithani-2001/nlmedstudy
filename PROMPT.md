# Master prompt (paste into any AI builder / designer)
Build a calm, premium online-study platform for a medical educator ("Your Personal Digital Medical Study Desk").
Not a course marketplace — a quiet private classroom: live classes (no social chat feed), daily handwritten notes in a
Notebook Mode (zoom, bookmark, highlight, ask doubt), resources, doubt support (Concept/Clinical/MCQ/Notes), assessments
with weak-area analysis (LEARN → TEST → FIND WEAKNESS → REVISE), progress, Focus Mode (45:00 timer), free demo class, and payments.
Teacher sets: course prices, topics, handwritten notes (PDF/scan), resources, demo sessions, doubts, announcements.
Look: ivory background, deep navy text, medical teal, soft green, lavender, subtle ECG lines, handwritten fonts, generous whitespace.
Avoid: Udemy/Coursera look, gradients, glassmorphism, red crosses, stock hospital photos, feeds, ads. Mobile-first with bottom nav
and an always-visible Free Demo button. Every screen answers: "What should the student study next?"
